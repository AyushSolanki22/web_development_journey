# Selectors
    Till now, we had seen element Selectors. in this chapter, we will learn lot of Selectors

    -Universal Selector
        to select everything in a document
        *{
            property:value;
        }

# Element Selector
    selects all elements of the same type (like that we learnt of in chapter 1)

# ID Selector
    select an element based on the value of the element id's attribute

    #myId{
        property:value;
    }

    note: For same property, Priority of selectors: id>class>element (_ _ _)
    incase, if Priority also matches. then last selector, one with same priority is given preference, (Cascading property)


# Class Selector
    selects an element based on their class attribute  (like we use id attribute, we can also use class attribute to group elements, even of different type)

    .myclass{
        property:value;
    }

# Practice - to set color inside divs with the id "myId" to wheat.
    div[id="myId"] p    OR   #myId p 


# Descendant Selector
    select all one child element under a one parent element       ((Parent/Ancestor -- Descendant))
 
    div p{
        property: value
    }

    can be used as in a multiple order, for eg-
    nav ul li {
        property:value;
    }

    //In this, u can skip multiple elements inside and select a certain child in heirarchy to get a certain property



# Sibling Combinator
    selector which certainly comes adjacent to another

    eg- h3 that comes immediately after any paragraph  (to apply property on all heading3 that comes immediately after a paragraph)
    p+h3{

    }

# Child Combinator
    selects all child elements which are direct children of a parent

    span>button{                       ((button which are direct children of span))
        property:value;        
    }

 
# Attribute Selector
    selects elements based on the presence or value of a given attribute

    input[attribute="value"] {    OR input[attribute] OR Many other types of writing
        property:value;
    }


# Pseudo class 
    A keyword added to a selector that specifies a special state of the selected element(s)

    :hover, :active , :checked, :nth-of-type                ((eg- button: hover))

    //nth-of-type(2)  OR nth-of-type(3n)


# Pseudo Elements
    A keyword added to a selector that lets you style a specific part of the selected elements  (for eg: first letter of a paragraph)
    double colon(::) is used 

    ::first-letter ,, ::first-line, ::selection (for selected part like as to copy,)


# Cascading
    CSS--> Cascading StyleSheets
    
    Cascade--> The CSS cascade algorithm's job is to select CSS Declarations(same selectors or same priority selectors) in order to determine the correct values for CSS Properties 
    
    Which value comes last for a same element, is applied (cascade)


    --Selector Specificity
        Specificity is an algorithm that calculates the weight that is applied to a given CSS Declarations(selectors)

        (3 digit number)
        _ _ _   (id ,, class,attribute & Pseudo class ,, element and pseudo element) (id>class>element)

        while scrolling Selectors in css file, we get to see selectors Specificity

        Notes:
        if same Specificity, Selectors coming last will be considered.(cascade)
        Inline style has more Specificity than id   (that is why we avoid using inline styles as it is impossible to change property through styling externally)

# !important in CSS
    to show the most important thing in document (having Specificity even more than that of inline style)

    h2{
        background-color: black !important;     (only this property will be applied overall)
    }


# Inheritance in CSS
    By the Inheritance property, element under one another element(heirarchy) may aquire it's parent/ancestor property

    input boxes,buttons by default do not inherit Properties from  parent/ancestor
    we have to specifically write to make them inherit Properties, 
    input{
        background-colon: inherit;
    }

    On a browser, using inspect feature, we can understand and infer styling basically , very good to analyse what will be right , what will be wierd

    properties like width, height, border & some others are non-inherit

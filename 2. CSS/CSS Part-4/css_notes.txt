# CSS Transform
    this property lets you rotate, scale,skew, or translate an elememt.
    tis properties also apply on the content within an elememt

    --rotate
        transform:rotate(45deg)  //clockwise rotate    OR  transform-rotate (-90deg)  //anti-clockwise rotate


    --scale
        transform: scale(0.5) or transform: scale(1.5)
        OR
        transform: scale(2,0.5)     //in x axis-double, in y-half
        OR
        transform: scaleX(0.5)  //only have a change in x axis (horizontal) -half  ((vice-versa as for scaleY))
    

    --translate
        transform: translate(50px,50px);    //move in x,y axis -- right,bottom**
        OR
        transform: translateX(10px);
        transform: translateY(10px);

    --skew
        skew() is a CSS transform that tilts an element along the X-axis, Y-axis, or both.

        transform: skew(30deg);   //skew(90deg) makes the element disapppear

# Position Property
    the Position CSS property sets how an elememt is positioned in a document.
    The top,right,bottom and left properties determine the final location of positioned elememts  ((top- from top))
    top,right,left,bottom--offsets

    static,relative,absolute,fixed

    --static
        The top,right,bottom,left and z-index properties have no effect
        This is the default value.

    --relative
        the offset is relative to itself based on the values of top,right,bottom and left.

    --absolute
        The element is removed from the normal document flow, and no space is created for the elememt in the page  layout.
        It is positioned relative to its closest positioned ancestor, if any; otherwise, it is placed relative to the initial containing block.

    --fixed 
        The element is removed from the normal document flow, and no space is created for the elememt in the page  layout.
        It is positioned relative to the initial containing block established by the viewport, except when one of its ancestors has a transform,
        perspective or filter property set to something other than none (in that case, ancestor behaves as the containing block)

        //Applications: floating chat button,back to top button, emergency widget

    --sticky (mdn)

# Object Literals 
    a data structure      //it is like class in  java    //Note: it's different from object (typeof arr--> object)

    object Literals -- used to store keyed collections & complex entities

        property => (key,value) pair                  //name , ayush --> property
        objects are collection of properties. 


# Creating Object Literals    //syntax  //terminated with semicolon //all key,value seperated by comma
    let delhi={
        latitude: "28.7041 N",
        longitude: "77.1025 E"
    };

    Note: it do not have a correct order as declared,,  on output.
    we can see, we can't see this much clearity in arrays  (key)

    Also, if object literal declared as const, it's reference will remain fixed (address cannot be changed)
    Also, we can include array within object literal

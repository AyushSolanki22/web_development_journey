# Query Selectors
    allows us to use any CSS Selector,,, it is frequently used 

    document.querySelector('p');  //selects first p element
    document.querySelector('#myId');   //selects first element with id=myId
    document.querySelector('.myClass');  //selects first element with class=myClass    //Remember - selects first element

    document.querySelectorAll("p");   //selects all p elements with a dataType = NodeList  (accessible like array)

    //can just write all css selector queries here,  (eg-- div a)

# Manipulating attributes

    //Getters & Setters
    obj.getAttribute(attr);     //gets the attribute of a specific object    -- id, class, src are all attributes
    obj.setAttribute(attr,val);    //sets the attribute to a value of a specific object   //for class, a object can then have only one class , so advised not to use much


# Manipulating style  (using style attribute)
    obj.style

    eg-- para.style.color='purple';    para.style.borderRadius="100%";
    Note: like in CSS, it is background-img (with hyphen), , in JS, the name is in camelCase. - backgroundImage

    Note: we can only access/manipulate inline styling with style attribute,, so it is not frequently used


# classList Property
    //using classList
    obj.classList   //we can see all classes associated with the Object

    classList.add()       to add new classes
    classList.remove()    to remove classes
    classList.contains()  to check if class contains " "
    classList.toggle()    to toggle between add & remove     //toggle like a switch   //it return the work it did , if add- true, if remoce - false

    Note: this can be used for like for some classes styling defined in style.css appliance can be varied by associating or not associating object with the class

# Using axios
    Axios -- Library to make https requests    ....  axios.get(url)

    till now, we have talked of, used fetch method. Axios also internally use fetch, but it's more compact, better method to send requests  (know more online -- axios github)
    we can either download to use it OR use cdn link to access it (before app.js)  <script src="https://cdn.jsdelivr.net/npm/axios@1.13.2/dist/axios.min.js"></script>

    we can see different different axios methods in documentation   //axios also returns promise by default
    Why axios then? -- the returning form of fetch was not in the form of JSON, we had to parse it everytime,,, by axios, the returned data is in the form of JSON only

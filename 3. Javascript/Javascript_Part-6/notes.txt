# Scope     
    scope determines the accessibility of variables, objects, and functions from different parts of the code.

    -function, -block, -lexical(nested functions), -global

    variables defined inside a function/block are not accessible (visible) from outside the function/block

    Note: block scope applies on variables declared with let, const, ,, not with var   //Note: automatically(not specified), variables are declared with var

#  Methods in objects
    actions that can be performed on objects

    const calculator ={                 //variable as key,,,, function as val
        add: function(a,b){
            return a+b;
        };
        sub: function(a,b){
            return a-b;
        };
    }

    //shorthand
    const calculator={
        add(a,b){
            return a+b;
        };
        sub(a,b){
            return a-b;
        };
    }

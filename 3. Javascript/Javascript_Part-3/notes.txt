# String methods
    methods- actions that can be performed on objects   (functions)

    format -->  stringName.method()      // like log.console(), alert()


# trim() method
    str.trim() --> trims whitespaces from both ends of string & return a new one.


# String immutability
    string is immutable --> no changes can be made to string originally
    whenever we do try to make a change, a new string is created and old one remains stringName


# toUpperCase & toLowerCase
    str.toUpperCase() , str.toLowerCase() --> return a new string after changing its case 


# String methods with arguments
    argument is a some value that we pass to the method.

    format --> stringName.method(arg)    // like indexOf

    ~indexOf
        returns the first index of occurence of some value in string. Or gives -1 if not found.
        // str="IloveCoding"     ,,, str.indexOf("love") --> 1 


# Method Chaining
    using one method after another. Order of execution will be left to right.

    //str.toUpperCase().trim()

# Slice Method
    returns a part of the original string as a new string

    str.slice(si) OR str.slice(si,ei) OR str.slice(-num)    //ei--> exclusive **    //-num = length-num


# Replace Method
    searches a value in the string & returns a new string with the value replaced  //Note: only first occurence is replaced
    //str="IloveCoding";     str.replace("love","do"); //"IdoCoding"

    repeat method 
        returns a string with the number of copies of a string

        //str="Mango";    str.repeat(3) //"MangoMangoMango"

# Keyboard events
    keydown (fired when a key is pressed) ,,, keypress (fired when a key that produces a character is pressed down) ,,, keyup (fired when a key is released)

    the Keyboard event have two imp. properties --- key (contains text what is written by through keyboard - what is being displayed) , code (a code corresponding to key. eg-- 'Space', 'keyA')

# More Events   
    change event
        the change event occurs when the value of an element has been changed (only works on <input>, <textarea>, and <select> elements).   //Note: it only tracks change between initial, final state (after removing focus from input),, means it will not be fired on each individual typing

    input event
        the input event fires when the value of an <input>, <select> , or <textarea> element has been changed.  Note: this fires for every individual char change

    
    can create text editor -- using input event, p , input objects

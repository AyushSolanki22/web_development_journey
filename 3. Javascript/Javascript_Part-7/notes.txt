# try & catch
    the try statement allows you to define a block of code to be tested for errors while it is being executed.

    the catch statement allows you to define a block of code to be executed, if an error occurs in the try block.

    //helpful in website management as to avoid crashes incase of api connection errors 

    Note: catch should be written as along with try - must, otherwise error

    //we can also print error message by taking (err) as argument in catch & print err.

# Set timeout
    function of a window object       //set time for certain action to be done in how much time

    setTimeout(function,timeout)      //function - callback (a function being passed as argument)  //timeout in ms


# Set interval
    setInterval(function, timeout );         //syntax just like setTimeout

    difference is that: set timeout waits for specified time and then execute, whereas setInterval makes wait for specified time, and then execute, then again wait & execute and so on.


    clearInterval(id)     //stops the repeated process, //let id=setTimeout should be done when declaring setTimeout
